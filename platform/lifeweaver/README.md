# LifeWeaver

LifeWeaver owns optional AI providers, MCP, agents, RAG and related AI
capabilities within the proposed LifeLedger Platform. Any provider plugins
must use provider-neutral contracts; health-data access must use VitaFabric
and honor identity, consent and audit policies. AI and cloud providers are not
required for the local product core. Provider contracts, permissions and
trust boundaries require design before implementation.

Part of the LifeLedger Platform Architecture: LifeLedger, VitaFabric, and LifeWeaver.
