# Home Assistant Integration

This directory is the integration-layer location for a future Home Assistant
integration. No integration exists yet. If it exchanges health data, connector
execution and FHIR mapping belong to VitaFabric; any integration packaging or
client code must use VitaFabric's approved contracts, with provenance and
consent. This directory does not authorize direct database access or bypass
the proposed plugin trust model.

Part of the LifeLedger Platform Architecture: LifeLedger, VitaFabric, and LifeWeaver.
