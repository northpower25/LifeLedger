offline slice uses locally protected SQLite via VitaFabric; PostgreSQL and
TimescaleDB are possible later options, not prerequisites for that slice.

configuration exists yet.

Part of the LifeLedger Platform Architecture: LifeLedger, VitaFabric, and LifeWeaver.
