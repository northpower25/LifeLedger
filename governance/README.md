# Governance

LifeLedger is initially maintained by the repository maintainers. Participation
is open to everyone who follows the [Code of Conduct](../CODE_OF_CONDUCT.md).

## Decisions

Discuss routine changes in issues and pull requests. For significant changes,
open an [RFC](../rfc/) and invite community feedback; record lasting
architectural decisions as [ADRs](../adr/). Maintainers seek consensus and
consider privacy, security, interoperability, accessibility, and maintenance
cost. If consensus cannot be reached, repository maintainers make and explain
the final decision in the relevant issue, pull request, or RFC.

## Maintainers and changes

Current maintainers are the people with repository maintainer access. They
review contributions, manage releases and security reports, and enforce the
Code of Conduct. Changes to this model, including how maintainers are added or
removed, should be proposed publicly and decided through the RFC process.
