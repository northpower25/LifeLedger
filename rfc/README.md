# Requests for comments

Use [0000-template.md](0000-template.md) to propose substantial changes for
community review. Link the proposal to its issue or pull request and record
the outcome. See the [governance documentation](../docs/governance/) for
decision-making within the LifeLedger Platform Architecture (LifeLedger,
VitaFabric, and LifeWeaver).

Current platform proposals include [RFC-0001](0001-platform-direction.md) and
[RFC-0002: Platform Core Architecture](RFC-0002%20Platform%20Core%20Architecture).
Both are drafts, not accepted architecture or evidence of implemented
capabilities.
