# Security Policy

LifeLedger is not yet a released or production-ready product. There are no
supported releases at present. Do not submit real health information or
credentials when reporting a problem.

## Reporting a vulnerability

Please do not open a public issue for a suspected vulnerability. Use GitHub's
private vulnerability reporting on this repository's Security tab ("Report a
vulnerability") if available. If it is unavailable, contact a repository
maintainer privately through GitHub and request a secure reporting channel
before sharing details.

Include affected versions or commits, a description of the impact, and safe
reproduction steps using synthetic data. Maintainers should acknowledge the
report, coordinate investigation and remediation privately, and agree on a
disclosure plan with the reporter. Response times cannot yet be guaranteed.

See [security/](security/) for security design work.
