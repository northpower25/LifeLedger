# LifeLedger Mission

LifeLedger enables every individual to:

- collect health data
- organize health data
- understand health data
- share health data selectively

without surrendering ownership to platform vendors.

The project prioritizes:

1. Privacy
2. Transparency
3. Interoperability
4. User control
5. Open standards

## Internationalization

LifeLedger is designed as a multilingual platform.

All user-facing functionality must support:

- multiple languages
- locale specific formatting
- timezone handling

The platform shall never assume English-only usage.

The first supported languages shall be English and German across the documentation, product, and all modules.
