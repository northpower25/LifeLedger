# Unique Selling Proposition

## Core Differentiators

### Local First

No cloud required.

### Privacy First

User owns all data.

### AI Agnostic

Works with any AI provider.

### FHIR Native

FHIR is the canonical model.

### MCP Native

Built for AI agents.

### Open Source

Community governed.

### Lifetime Health Timeline

Not focused on short-term wearable metrics only.

Provides:

- longitudinal history
- family history
- documents
- medication
- laboratory data
- health twin

## Internationalization

LifeLedger is designed as a multilingual platform.

All user-facing functionality must support:

- multiple languages
- locale specific formatting
- timezone handling

The platform shall never assume English-only usage.

The first supported languages shall be English and German across the documentation, product, and all modules.
