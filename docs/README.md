# Documentation

`docs/` is the single source of truth for LifeLedger project documentation.
Authoritative technical standards and design specifications belong in
[`specifications/`](../specifications/), not here.

The LifeLedger Platform Architecture consists of **LifeLedger**, **VitaFabric**
and **LifeWeaver**. Start with the [repository overview](../README.md) and
[architecture](architecture/README.md). Documentation is design-stage guidance;
it does not imply that an application or platform implementation exists.
